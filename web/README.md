# web

Aplikasi situs smartagri (TanStack Start). Panduan menjalankan, variabel
lingkungan, dan alur kerja ada di [README utama](../README.md); aturan brand dan
konvensi kode ada di [CLAUDE.md](../CLAUDE.md).

```bash
npm run build
npx tsc --noEmit
npm test
```
